# พัสดุวอร์ด · หอผู้ป่วยโรคหลอดเลือดสมอง (Stroke Unit)

แอปเช็กสต๊อกพัสดุสำหรับธุรการประจำวอร์ด ไฟล์เดียว ไม่ต้องติดตั้งหรือ build
แอปนี้ **ไม่เชื่อมกับระบบเบิกจ่ายของโรงพยาบาล** ใช้เช็กสต๊อกและทำรายการช่วยจำเท่านั้น

## ฟีเจอร์
- หน้าหลักเป็นไอคอนหมวดหมู่ แตะเพื่อเปิดหน้ารายการพัสดุของหมวด เพิ่ม/แก้ไขหมวดและรายการได้ (เมนู จัดการ)
- สีสถานะ เขียว/เหลือง/แดง และแจ้งเตือนต่ำกว่า Min
- สแกน Barcode / QR (รหัสพัสดุ) ด้วยกล้อง หรือพิมพ์รหัส
- ตัดสต๊อก (หักล็อตที่หมดอายุก่อน FEFO) และแจ้งเตือนวันหมดอายุล่วงหน้า 1-3 เดือน
- รายการเบิกและเทมเพลต: ใช้เป็นรายการช่วยจำ คัดลอกข้อความไปกรอกในระบบเบิกของโรงพยาบาล
- รับของเข้าสต๊อก: บันทึกจำนวนที่ได้รับจริงและวันหมดอายุ
- รายงานยอดใช้รายเดือน ประวัติตัดสต๊อก/รับเข้า และข้อความสรุปส่งหัวหน้าหอผู้ป่วย

## เผยแพร่ด้วย GitHub Pages
1. อัปโหลดไฟล์ในโฟลเดอร์นี้ไปที่ root ของ repository
2. Settings > Pages > Deploy from a branch > main / (root)
3. เปิดลิงก์ https://<username>.github.io/<repo>/ (ต้องเป็น HTTPS เพื่อให้กล้องสแกนทำงาน)

## ข้อจำกัด (เว็บแอปฝั่งเบราว์เซอร์ล้วน ไม่มีเซิร์ฟเวอร์)
- ไม่ส่งใบเบิกหรือเชื่อมต่อระบบโรงพยาบาลใด ๆ
- ข้อมูลเก็บใน localStorage ของแต่ละเครื่อง ไม่ซิงก์ข้ามเครื่อง
- แจ้งเตือนผ่านแถบในแอปเมื่อเปิดใช้งานเท่านั้น ไม่มี push
- สแกนด้วยกล้องใช้ BarcodeDetector (Chrome/Edge บน Android) iOS Safari ส่วนใหญ่ใช้ไม่ได้ ให้พิมพ์รหัสหรือใช้เครื่องยิงบาร์โค้ดแทน
